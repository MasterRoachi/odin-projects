# Odin Projects

A collection of the projects I completed while studying through [The Odin Project](https://www.theodinproject.com/).

Each project is stored in its own folder and has an individual README describing its purpose, features, technologies, and learning outcomes.

## Projects

| Project                                                          | Description                                                                  |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| [Admin Dashboard](./admin-dashboard/README.md)                   | A static dashboard interface built to practise complex CSS Grid layouts.     |
| [Coolculator](./calculator/README.md)                            | A browser-based calculator with keyboard controls and chained operations.    |
| [Etch-A-Sketch](./etch-a-sketch/README.md)                       | An interactive JavaScript drawing grid with custom sizing and drawing modes. |
| [Odin Recipes](./odin-recipes/README.md)                         | A three-page recipe site built to practise structural HTML.                  |
| [Landing Page](./landing-page/README.md)                          | A personal landing page built from the Odin design brief.                    |
| [Quartz, Parchment, Shears](./Quartz-Parchment-Shears/README.md) | A themed browser-based Rock Paper Scissors game.                             |
| [The Ark](./library/README.md)                                    | A personal library kept as spines on a shelf.                               |
| [Quarry Sign-up Form](./sign-up-form/README.md)                  | A sign-up form with live validation, for an invented service.                |

## Technologies Used

Projects in this repository use combinations of:

* HTML
* CSS
* JavaScript
* Flexbox
* CSS Grid
* DOM manipulation

## About This Repository

This repository consolidates my Odin Project assignments into one central location while retaining the original Git histories where they were available.

Additional projects will be added as I continue through the curriculum.
