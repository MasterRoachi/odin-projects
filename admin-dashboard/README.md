# Admin Dashboard

A static admin dashboard interface built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## Overview

The goal of this project was to reproduce a complex dashboard layout using HTML and CSS. The page combines a navigation sidebar, header controls, project cards, announcements, trending users, and reusable interface icons.

## Features

* Sidebar navigation
* Search and account controls
* Project card grid
* Announcements section
* Trending-users section
* Inline SVG icons
* Structured dashboard layout

## Built With

* HTML
* CSS
* CSS Grid
* Flexbox
* SVG

## What I Practiced

This project helped me practise:

* Building page-level layouts with CSS Grid
* Combining Grid and Flexbox
* Creating nested layouts
* Organising complex interfaces into sections
* Reusing card and navigation styles
* Managing spacing, alignment, typography, and visual hierarchy

## Project Status

Completed as a static layout project. The controls and navigation elements are visual and do not currently have application functionality.
