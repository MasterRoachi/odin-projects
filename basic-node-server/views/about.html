What happened

  1. Your browser opened a socket and sent a method, a path and some headers.
  2. createServer handed that to one function as req.
  3. The path was looked up in a table of three routes.
  4. A status code was chosen, a content type set, and a body written.

The codes this server sends

CodeWhen
200One of the three pages, fetched with GET
400You posted the contact form with an empty message
403A static path that tried to climb out of public/
404Any path not in the table
405A real path, wrong method — and it tells you which are allowed
413A request body over 10kB
415Posting something that is not form encoding
500The handler threw
