DWG. 04 — BINARY SEARCH TREE

Two Trees

The same values, twice. On the left, built by taking the middle value as the root and repeating. On the right, built by inserting the values one at a time in sorted order — which is a linked list wearing a tree costume.

Search both at once and count the comparisons. That gap is the entire reason isBalanced and rebalance exist.
