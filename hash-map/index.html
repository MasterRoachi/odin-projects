Buckets

Every column is a bucket. Each tile is a key–value pair, coloured by its own hash, so the same key is always the same colour. A column with more than one tile is a collision. Fill it past three-quarters and watch the whole thing double and redeal.

What happened

    Buckets are the linked list from the Linked Lists project, imported rather than rewritten. Built for The Odin Project.
