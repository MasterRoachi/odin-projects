Twenty-four projects, rebuilt from nothing.

I went back to the start of the curriculum and built every project again — not to repeat the exercises, but to do them properly. Twenty of them are hand-written HTML, CSS and JavaScript with no framework at all; three are React. Everything opens in a browser except the two that belong in a terminal and the servers, which run locally.

About this page

This is itself a project — the one at the end of Advanced HTML and CSS. There is no JavaScript on it at all. The grid reflows on its own with auto-fill and a minmax floor rather than by breakpoint, every colour pair was measured against the 4.5:1 contrast requirement before being used, the nineteen marks are inline SVG that inherit their colour, and all of the motion turns itself off for anyone who has asked their system for less of it.

Source, and a written record of what went wrong in each project, at github.com/MasterRoachi/odin-projects.

Built by Master Roachi while working through The Odin Project.
