# Questicles Landing Page

A gaming-themed landing page built as part of [The Odin Project Foundations](https://www.theodinproject.com/) curriculum.

## Overview

Questicles is a fictional gaming website focused on gaming news, reviews, and analysis. The project applies the HTML and CSS fundamentals covered during the Foundations course to a complete multi-section landing page.

## Features

* Branded hero section
* Gaming-focused introductory content
* Information sections
* Call-to-action content
* Structured page footer
* Custom colours, typography, and layout

## Built With

* HTML
* CSS
* Flexbox

## What I Practiced

This project helped me practise:

* Structuring a complete webpage with HTML
* Building layouts with Flexbox
* Applying the CSS box model
* Controlling spacing and alignment
* Creating visual hierarchy with typography
* Styling buttons and page sections
* Turning a design brief into a finished webpage

Completed as a static landing-page project.
