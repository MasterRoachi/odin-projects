# KOI Restaurant Page

A responsive restaurant website for KOI, a fictional Japanese street-food restaurant. The page is generated dynamically with JavaScript and uses tabbed navigation for the Home, Menu, and Contact sections.

## Features

- Dynamically generated page content
- Home, Menu, and Contact tabs
- Responsive menu-card grid
- Active navigation states
- Mobile-friendly layout
- Clickable telephone and email links
- Custom KOI branding and artwork

## Built With

- HTML
- CSS
- JavaScript
- Webpack

## What I Practised

- Organising JavaScript into modules
- Importing images and CSS with Webpack
- Generating DOM elements with JavaScript
- Rendering data from an array of objects
- Switching page content with event listeners
- Building responsive layouts with Flexbox and Grid
